# Vision Documents

This directory contains living documents describing where this project is headed.
The `/guide` skill reads these to orient new collaborators and suggest work.

Each file is a standalone markdown doc describing a goal, direction, or area of
focus. There's no required structure — write them the way you'd explain the
vision to a teammate.

Vision docs inform what gets built. When someone runs `/guide I want to work on
something`, the guide reads these files, compares them to the current state of
the code, and suggests concrete next steps.
